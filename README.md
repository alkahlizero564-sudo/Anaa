# Anaa — اعثر على هاتفك المفقود

تطبيق ويب (PWA) بالعربية للعثور على هاتفك: تسجّل الدخول بالبريد الإلكتروني، تفعّل المشاركة على هاتفك، ثم ترى من أي جهاز آخر **موقعه على الخريطة، ونسبة البطارية، وحالة الاتصال والشبكة**.

## المميزات
- 🗺️ موقع الجهاز على الخريطة (OpenStreetMap) مع دائرة دقة الموقع، ومسار آخر 24 ساعة.
- 🔋 نسبة البطارية وهل الجهاز يشحن.
- 🟢 الحالة: متصل / آخر ظهور، نوع الشبكة (واي فاي، 4G…)، وهل التطبيق ظاهر أم في الخلفية.
- 🔔 **رنين** بصوت عالٍ واهتزاز حتى لو كان الهاتف على الصامت داخل التطبيق.
- 🚨 **وضع الفقدان**: رسالة على شاشة الهاتف مع زر للاتصال بك.
- 📍 طلب موقع فوري، و🧭 الاتجاهات إلى الجهاز عبر خرائط جوجل.
- عدة أجهزة لكل حساب، وإعادة التسمية والحذف.

## الخصوصية والموافقة
- لا يمكن تتبع أي هاتف إلا بعد تسجيل الدخول **على الهاتف نفسه** والموافقة الصريحة على المشاركة.
- يظهر على الهاتف شريط واضح «هذا الجهاز يشارك موقعه الآن»، ويمكن إيقاف المشاركة منه في أي وقت.
- كلمات المرور مشفّرة بـ scrypt، والرموز مخزّنة كـ hash، وكل مستخدم يرى أجهزته فقط.

## التشغيل
يتطلب Node.js 22.5 أو أحدث، بدون أي مكتبات خارجية.

```bash
npm start          # http://localhost:3000
npm test           # اختبارات الـ API
```
متغيرات اختيارية: `PORT`، `DB_FILE` (الافتراضي `data/anaa.db`).

> ⚠️ تحديد الموقع في المتصفح يتطلب **HTTPS** على الهاتف. عند النشر ضع التطبيق خلف HTTPS (مثل Caddy أو Nginx أو أي استضافة تدعمه).

## طريقة الاستخدام
1. افتح التطبيق على هاتفك وأنشئ حسابًا.
2. اختر «هذا الجهاز» ← اكتب اسمًا ← وافق ← «تفعيل المشاركة»، واسمح بإذن الموقع.
3. (مستحسن) ثبّت التطبيق على الشاشة الرئيسية وفعّل «إبقاء الشاشة مضاءة».
4. من أي جهاز آخر سجّل الدخول بنفس البريد وافتح «أجهزتي».

## القيود الحالية
تطبيق الويب يرسل الموقع **ما دامت الصفحة مفتوحة** فقط؛ المتصفحات لا تسمح بالتتبع في الخلفية. الخطوة التالية المقترحة هي تطبيق أندرويد أصلي يستخدم نفس الـ API للإرسال في الخلفية، وبعد إعادة التشغيل، وعند انخفاض البطارية.

## البنية
```
server/app.js    الـ API والملفات الثابتة (node:http)
server/db.js     قاعدة بيانات SQLite المدمجة (node:sqlite)
public/          الواجهة: لوحة الأجهزة + وضع التتبع + PWA
test/            اختبارات node:test
```

### الـ API
| | المسار | الوصف |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | `{email, password}` ← `{token}` |
| GET | `/api/devices` | أجهزة المستخدم مع آخر حالة وموقع |
| POST | `/api/devices` | `{name, consent: true}` ← `{deviceToken}` |
| GET | `/api/devices/:id/history?hours=24` | مسار الجهاز |
| POST | `/api/devices/:id/commands` | `ring` / `locate` / `lost_mode_on` / `lost_mode_off` |
| POST | `/api/device/report` | (برمز الجهاز) إرسال الموقع والبطارية، ويعيد الأوامر المعلّقة |
| GET | `/api/device/commands` | (برمز الجهاز) الأوامر المعلّقة |
| DELETE | `/api/device` | (برمز الجهاز) إيقاف المشاركة |
